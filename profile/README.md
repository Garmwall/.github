### What we work on

**Garmwall** is a firewall for AI agents, written in Rust. It sits between an agent and the tools it connects to over the Model Context Protocol (MCP), pins every tool definition, inspects calls and results, and asks a human before anything risky happens.

### Repositories

| --- | --- | --- |

### Principles

- **Open source first.** The core is and stays Apache-2.0.
- **Local by default.** Your prompts, code and secrets never leave your machine.
- **Honest about limits.** We reduce the blast radius; we never promise perfect safety.
- **Built in public.** Design decisions, roadmap and progress happen in the open.

### Get involved

- Follow the organization and star [`garmwall`](https://github.com/Garmwall/garmwall) to see progress
- Share ideas, questions and use cases in Discussions
- Report security issues privately through the repository's security advisories, never in a public issue
